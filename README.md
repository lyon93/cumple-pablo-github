# Cumple Pablo

Sitio estatico listo para publicar en GitHub Pages.

## Estructura

- `index.html`
- `img/pablo.jpg`

## Cambiar la foto

Sustituye `img/pablo.jpg` por la foto real de Pablo manteniendo ese nombre.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube el contenido de esta carpeta al repositorio.
3. En GitHub abre `Settings > Pages`.
4. En `Build and deployment`, elige `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/(root)`.
6. Guarda y espera a que aparezca la URL del sitio.
